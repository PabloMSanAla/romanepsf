## 2. Logic Chain

1. **Precedence Architecture for Data Loading**:
   - From Observation 1.3, programmatic callers (e.g., `pipeline.py` or unit tests) can provide `ValidationResults` directly on `ReportDataBundle.validation_results`.
   - From Observation 1.2, CLI executions save multi-extension FITS files to disk under `output/validation/residual_{tier}_{source_id}.fits` or `results_dir / "validation"`.
   - To make `plot_page_subtraction_residuals` fully robust across all operating modes without hardcoding, we established a 3-tier discovery hierarchy in `load_tier_residual_data`:
     1. **Priority 1 (In-Memory)**: If `data.validation_results` contains `star_results: List[StarResidualResult]`, extract authentic arrays directly without disk I/O.
     2. **Priority 2 (Disk FITS)**: Search candidate directories (`results_dir / validation`, `results_dir`, `output/validation`, `output/run_all/validation`) for `residual_{tier}_*.fits`. If multiple exist, select the star with the lowest `CHI2_NU` in the primary header.
     3. **Priority 3 (Deterministic Fallback)**: If neither in-memory results nor FITS files exist (e.g., lightweight standalone tests), derive cutout models cleanly from `data.epsf` with deterministic zero residuals and reduced chi2 of 1.0, explicitly tagged as `[Deterministic Mock]` without claiming real Level 2 observation.

2. **Complete 5-Map Visualization**:
   - The mission instructions explicitly require displaying:
     1. Real Observed star image from `OBSERVED` HDU.
     2. Real Forward Model from `MODEL` HDU.
     3. Real Residual from `RESIDUAL` HDU.
     4. Real Normalized Residual from `NORM_RES` HDU.
     5. Real Fractional Residual from `FRAC_RES` HDU.
     6. Real fitted parameters from FITS header cards: `MAG`, `FLXSCALE` ($\alpha$), `DX`, `DY`, `CHI2_NU`.
   - We organized the page into 3 rows (Bright, Medium, Faint) $\times$ 5 columns:
     - Column 0: Observed $I_{\text{obs}}$ (LogNorm, viridis)
     - Column 1: Model $I_{\text{model}}$ (LogNorm, viridis, identical color scale to Observed)
     - Column 2: Residual $R$ (coolwarm, centered at 0 with limits derived from 98th percentile of unmasked pixels)
     - Column 3: Normalized Residual $Z$ (RdBu_r, range $[-5.0\sigma, +5.0\sigma]$)
     - Column 4: Fractional Residual $F$ (PuOr_r, range $[-0.5, +0.5]$)
   - Fitted parameters are displayed in an annotation box in Column 4 and row y-labels:
     `\chi_\nu^2 = {chi2}`, `\alpha = {flx}`, `(\Delta x, \Delta y) = ({dx}, {dy})`, `m = {mag}`.
   - Dual colorbars on the right margin display scales for Normalized Residual $Z$ and Fractional Residual $F$.

3. **Subpixel Zoom and Cropping**:
   - Raw star stamps are $1001 \times 1001$ (bright), $201 \times 201$ (medium), and $81 \times 81$ (faint).
   - Displaying $1001 \times 1001$ at 1.2 inches compresses the core ($r < 10$ px) to under 2% of the panel width, obscuring core and transition subtraction behavior.
   - We apply central cropping around continuous center `((obs.shape[0]-1)//2, (obs.shape[1]-1)//2)`:
     - Bright: crop size 101 $\times$ 101 (radius 50 px) — captures core, transition, and all 12 diffraction spike rays.
     - Medium: crop size 61 $\times$ 61 (radius 30 px) — captures core and transition overlap.
     - Faint: crop size 41 $\times$ 41 (radius 20 px) — expands core pixels for clear examination.
   - Bounds safety: `h = min(crop_sz // 2, cy, cx)` guarantees that any stamp size is handled without index errors.

4. **Elimination of Facades**:

## 3. Caveats

1. **Core Saturation in Bright Stars**:
   - In simulated Roman Level 2 data, bright stars ($m < 11.0$) have saturated central cores ($r < 10$ px) where detector DQ flags mark pixels as saturated. The forward model extrapolates unattenuated flux into the core, resulting in large nominal residuals ($R < 0$, $\chi_\nu^2 \sim 14,919$) in unmasked/partially masked core pixels.
   - To prevent saturated core pixels from blowing out the color scale of Column 2 (Residual), the residual color limit `res_lim` is calculated using unmasked pixels (`mask == 0`), defaulting to the 98th percentile of $|R|$.
